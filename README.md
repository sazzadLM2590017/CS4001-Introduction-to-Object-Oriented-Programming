CS4001 Gadget Shop
This project is a Java-based application developed to manage different types of gadgets using object-

oriented programming concepts. The system includes a superclass called Gadget and two subclasses 

called Mobile and MP3. The program also includes a graphical user interface (GUI) that allows users to 

interact with the system easily. The main aim of this project is to demonstrate concepts such as 

inheritance, encapsulation, and polymorphism.
